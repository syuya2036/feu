# Examples

This directory contains examples of how to use `feu` with different adapters.

## Todo App (Hyper Adapter)

This example demonstrates a simple Todo application using the `hyper` adapter and standard middleware (`logger`, `pretty_json`).

### Running the Example

```bash
cargo run -p feu --example todo --features hyper,json
```

### Verification (curl)

Open a new terminal and run:

**1. Create a Todo**
```bash
curl -v -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -d '{"title": "Buy milk"}'
```
*Expected Output:* JSON response with created todo (id: 1) and status `201 Created`.

**2. List Todos**
```bash
curl -v http://localhost:3000/todos
```
*Expected Output:* JSON array containing the created todo.

**3. Check Logs**
In the terminal running the example, you should see logs generated by the `logger` middleware (e.g., `METHOD path status duration`).
